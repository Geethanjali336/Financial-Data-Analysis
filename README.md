# Financial-Data-Analysis
**Domain: Finance
Source: Kaggle.com
Tool: Microsoft Power BI**

This project is focused on creating a dynamic financial summary dashboard that delivers clear visibility into sales, profit, and operational trends. Through intuitive visuals and KPIs, the dashboard helps users analyze performance across multiple dimensions. It demonstrates strong data modeling, DAX skills, and dashboard design principles.


In this project, I developed an interactive Financial Summary Dashboard using Power BI to help businesses gain a clear understanding of their overall financial performance. The report highlights key KPIs such as total sales, profit, units sold, gross sales value, net profit margin, product performance, regional distribution, customer segments, and monthly sales trends.


During this project, I learned how to:

Build dynamic dashboards in Power BI using DAX measures, slicers, and interactive visuals.

Design insights for sales by product, segment, discount bands, month, and country.

Apply data modeling and data preparation techniques including cleaning, merging, and creating calculated tables/measures.

Use advanced Power BI features such as formatting options, buttons, bookmarks, tooltips, and conditional formatting to highlight important insights.

Create visually appealing and user-friendly dashboards with clear KPIs and consistent design themes.

Analyze financial metrics effectively to uncover business opportunities and operational gaps.



Overall, this project helps organizations optimize financial decisions, enhance profitability, and discover actionable insights across multiple business dimensions. It also strengthened my ability to perform end-to-end BI development—from transforming raw data to delivering an executive-ready financial dashboard.
